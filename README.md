# Gravitational-memory-thesis
Code used while writing astrophysics senior thesis at Haverford College entitled "The Effect of Gravitational Memory on CMB Light."

Author: Simon Thill <sthill12321@gmail.com>

Advisor: Professor Daniel Grin


All of the code used in my thesis can be found in the Thesis_code folder. All plots were created using python code and can be found in the .ipynb Jupiter notebook files. Mathematical calculations were done using Mathematica and can be found in the Thesis_Calculations notebook. 

The Dev_and_Debugging folder contains some of my first attempts which were unsucessful, or later had to be corrected. Most of this will not be useful to anyone besides myself, however, there is a backup of my calculation notebook which I created in February 2025. There is also a Thesis_testing mathematica notebook which contains some of the next steps in my project, which is still in progress.
